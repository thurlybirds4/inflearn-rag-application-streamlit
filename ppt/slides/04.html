WHAT IS RAG
RAG란
외부 문서나 DB에 데이터를 저장해 두고,
LLM이 답변을 생성할 때 해당 문서를 먼저 찾아 참고하도록 만드는 방법
동작 3단계
RRetrieval찾아내다
질문과 관련된 정보를 Vector DB에서 찾아낸다
AAugmented보완하다
찾아낸 정보를 프롬프트에 덧붙여 보완한다
GGeneration생성하다
덧붙여진 정보를 참고해 정확도 높은 답변을 생성한다
VECTOR DB & EMBEDDING
Vector DB란
비정형 데이터를 벡터 임베딩 형태로
저장하고 관리하는 데이터베이스
원리와 역할
01Embedding임베딩

02Similarity Search유사도 검색
질문과 맥락상 가장 가까운 정보를 찾아 프롬프트를 보완한다
