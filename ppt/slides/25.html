STREAMING GENERATOR

스트림을 딕셔너리처럼 읽어서 깨졌다

PROBLEM
tax_chain.stream(...) 결과를 ai_response["answer"]처럼 접근해 오류가 났다.
CAUSE
.stream()은 전체 결과 dict가 아니라, 청크를 차례로 주는 Iterator / Generator다.
SOLUTION
.pick('answer')로 답변만 남긴 뒤 객체 자체를 반환해 st.write_stream이 그리게 했다.
INSIGHT
Chain의 반환 타입을 코드에서 확인하는 일이 구현의 핵심이었다.
tax_chain = ({"input": dictionary_chain} | rag_chain).pick('answer')
ai_response = tax_chain.stream(...)
return ai_response          # not ai_response["answer"]
