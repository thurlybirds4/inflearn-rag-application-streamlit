01
LIBRARY VERSION

강의 v0.2와 지금 버전이 달랐다

PROBLEM
강의는 LangChain v0.2, 현재는 v1.3x. 코드를 그대로 쓰면 호환이 깨질 수 있었다.
CAUSE
프로젝트 코드가 강의 당시 버전 기준이라, 최신 패키지를 그대로 깔면 의존성이 어긋날 수 있었다.
SOLUTION
제공된 requirements.txt로 버전을 맞추고, 쓰는 패키지 버전을 명시했다.
INSIGHT
최신 라이브러리보다 코드와 버전이 맞는지가 중요했다.
%pip install -r requirements.txt
%pip install langchain-google-genai==2.0.1 -q
02
EMBEDDING MODEL NAME

문서의 모델명을 그대로 쓰면 깨졌다

PROBLEM
공식 문서의 gemini-embedding-001을 넣었더니 model name format 오류가 났다.
CAUSE
문서의 이름만 보고 썼고, 실제 API가 요구하는 models/ 접두사를 확인하지 않았다.
SOLUTION
내 API 키로 쓸 수 있는 모델을 조회해 models/ 접두사가 필요함을 확인했다.
INSIGHT
코드를 고치기 전에 지금 쓸 수 있는 모델과 스펙을 확인하는 디버깅이 먼저였다.
for m in genai.list_models():
    if 'embedContent' in m.supported_generation_methods:
        print(m.name)
